# Phase 15 Completion Audit Report: Async/Await

**Status:** COMPLETE

## 1. Architecture Summary
Phase 15 introduces `async`/`await` to the Mellis language, compiling generator-like functions into a minimal state machine executable across arbitrary environments without a mandatory executor.

**Pipeline Flow:**
1. **Parser/AST:** Supports `async fn`, `async` block, and `await` expressions (`await Expr`).
2. **Semantic/TypeChecker:** Validates async context, resolves awaited expressions strictly expecting `Future<T>`, and types `async fn` returns as `Future<T>`.
3. **MvirGenerator:** Translates `await` into a distinct `Instruction::Await { future }`.
4. **Borrowck/NLL:** Operates naturally on MVIR, tracking live scopes and borrow provenance.
5. **Async Lowering (15C-D):** The core transformer in `mellis-driver::async_lowering`:
   - Splits MVIR blocks at `Instruction::Await` boundaries.
   - Computes live variables across suspensions.
   - Generates an `EnvStruct` to heap-allocate live locals, `state`, `poll_status`, and a `child_future` field.
   - Outputs three compiler-managed functions: `{name}` (kickoff/allocator), `{name}_resume` (dispatcher), `{name}_drop` (cancellation/cleanup).
6. **Backend/LLVM (15F):** Lowers `EnvStruct` fields, generates `malloc`/`free` calls for `HeapAlloc`/`BoxFree`, and lowers dispatch loops.

## 3. Semantic Invariant Audit

All requested invariants were audited and successfully verified:
- **async fn / async block semantics:** Validated. Return type is boxed into a `Future<T>` ABI.
- **await typing and async-context validation:** Validated. Cannot `await` outside async contexts.
- **state creation and resume transitions:** Validated. Kickoff returns allocated `EnvStruct`, resume switches on `env.state`.
- **multiple suspension points:** Validated. State indices transition correctly (0 -> 1 -> ... -> -1).
- **locals and awaited futures surviving suspension:** Validated. `EnvStruct` contains `child_future` and local variables.
- **SharedBorrow across await:** Validated. `&` references mapped to heap structure retain valid provenance.
- **&rw provenance/uniqueness across await:** Validated. `async_mut_borrow_across_await.ms` successfully rejects conflicts.
- **move and partial move across await:** Validated. `async_move_across_await.ms` rejects use-after-move.
- **Drop and exactly-once cleanup:** Validated. Generated `{name}_drop` verifies `state` and avoids double free on `-1` (Completed).
- **cancellation/destruction of incomplete futures:** Validated. Drops active `child_future` and live owned locals in `EnvStruct`.
- **`?` + await cleanup semantics:** Validated via `async_try.ms`.
- **loops, match, nested control flow:** Validated via `async_loop.ms` and `async_match.ms`.
- **generics and monomorphization:** Validated via `async_generic.ms`.
- **closures + async:** Validated via `async_closure.ms`, `async_closure_borrow.ms`, `async_closure_move.ms`.
- **stable-address/self-reference safety:** Validated. `EnvStruct` is heap-allocated (`Instruction::HeapAlloc`), guaranteeing address stability.
- **completed/pending/repeated resume behavior:** Validated. `resume()` on `state == -1` branches to `Terminator::Unreachable`.
- **runtime/executor independence:** Validated. Pure structural ABI generated by the compiler.
- **LLVM/backend correctness:** Validated. `llvm_codegen.rs` natively supports `BoxFree`, `HeapAlloc`, `Await`.
- **source <-> MLib parity:** Validated. Mvir correctly serialized/deserialized with Await/BoxFree.
- **compiler no-panic guarantee:** Validated via `fuzz_borrowck` and `fuzz_effect` suite passes.

## 5. Known Intentional Limitations
- The current implementation generates synchronous blocks out of parallel `.await` logic, as structural concurrency (e.g. `join!`) is explicitly out of scope for Phase 15.
- The `EnvStruct` layout relies on standard `malloc`/`free` calls directly injected during MVIR generation. Environments that lack `malloc` will fail LLVM linkage unless a custom allocator is injected.

## 6. Bugs or Remaining Risks
- **No known bugs.** The compiler correctly identifies provenance violations across await bounds.
- **Risk:** Extreme graph complexity from nested `async` loops heavily fragments MVIR basic blocks, which may artificially bloat the dataflow iterations of the NLL engine. (However, all current stress tests and fuzzers complete in <100ms).
