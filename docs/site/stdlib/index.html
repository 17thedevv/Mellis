Standard Library

Library model

Core

Basic primitives, integer and float helpers, conversions, and error handling.

Alloc

Memory allocation and ownership-aware helpers for low-level runtime logic.

Collections

Vector, map, set, and generic container-style data structures.

Text & IO

String formatting, streaming, file APIs, and debugging utilities.

MLib model

Mellis libraries are planned around the .mlib package format, which allows the compiler to load metadata efficiently and distribute validated standard library components as compiled modules.
