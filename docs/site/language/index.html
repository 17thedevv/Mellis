Language

Overview

Mellis is a systems-oriented language designed around explicit ownership, expression-oriented syntax, strong static typing, and compiler-driven code generation. The language is intended to be fast, predictable, and readable while still retaining the low-level control needed for systems work.

Syntax

The syntax favors compact declarations, block expressions, and direct control flow. Function bodies can express values implicitly and keep the reading model close to the compiler’s internal AST.

Types

Mellis includes primitives, arrays, tuples, structs, enums, closures, and generic abstractions. Type inference is used where it helps readability, while explicit annotations remain available when needed.

Ownership & Borrowing

Ownership keeps the lifetime story explicit. Borrowing allows temporary, non-owning access with compiler checks that preserve memory safety without introducing a heavy runtime model.

Generics & Traits

Generic programming is powered by type parameters and trait constraints, allowing code reuse without inheritance-heavy object modeling.

Closures

Closures capture environment state and behave like first-class values, enabling functional style patterns while preserving static analysis.

Pattern Matching

Pattern matching is a core form of control flow. It is used for enum handling, tuple destructuring, and structured value analysis with exhaustive checks.
