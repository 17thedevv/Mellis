Compiler

Architecture and pipeline

Frontend

Lexer, parser, and AST construction build the program representation before semantic checks begin.

Middle-end

Type checking, pattern analysis, borrow rules, trait solving, and MVIR lowering are all part of the semantic pipeline.

Backend

LLVM is the native backend; the compiler emits IR and then delegates final assembly and linking to the toolchain.

Pipeline

Source → Lexer → Parser → AST → Semantic Analysis → MVIR → LLVM IR → Machine Code
